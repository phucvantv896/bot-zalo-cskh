Khung chat bán hàng

Đây là trang thử. Bấm nút chat ở góc phải dưới để nói chuyện với bot, giống hệt khách sẽ thấy trên website của shop.

Mã nhúng vào website

Dán một dòng này vào cuối trang (trước thẻ </body>) của website shop:


    
    
    
      
  1. WordPress: cài plugin WPCode → Code Snippets → Header & Footer → dán vào ô Footer → Lưu.
    2. 
      
  2. Haravan / Sapo / Shopify: sửa giao diện → tệp theme.liquid → dán ngay trước </body>.
    3. 
      
  3. WebCake / LadiPage: thêm khối HTML/Mã nhúng hoặc mục Mã chèn cuối trang → dán.
    4. 
    

    
Đổi màu: thêm data-mau="#c2185b". Đặt nút sang trái: thêm data-vi-tri="trai".

  


  

    Website phải chạy https:// và bot phải có tên miền (https) thì khung chat mới hiện trên website thật.
    Trình duyệt chặn website https tải mã từ địa chỉ http://IP.
